## Log (`outputs/logs/predictions.jsonl`)

บันทึกทุกคำทำนาย **ก่อนรู้ผล** ต่อท้ายไฟล์ ห้ามแก้ย้อนหลัง ฟิลด์:
`prediction_id, symbol, session, date, data_cutoff, source_received_at, generated_at, submitted_at, model_version, feature_version, reference_price, reference_time, p_up, direction, z_quantiles, price_quantiles, point_price, fallback_reason`
— actuals ถูกเพิ่มภายหลังโดย `06_score_live.py` ในไฟล์แยก (`outputs/reports/live_scored.csv`)

## แผนสำรอง

| ปัญหา | ระบบทำอะไร | คนทำอะไร |
|---|---|---|
| โมเดล / features ล้ม | ใช้ **baseline** จากข้อมูลล่าสุดที่ผ่านเกณฑ์ + ธง `fallback_reason` | ส่งตามไฟล์ แล้วดูสาเหตุหลังส่ง |
| ราคาอ้างอิงรอบบ่ายเก่าเกิน `max_price_age_min` | ทำนายต่อแต่ติดธง | ตรวจว่าไฟล์รายนาทีอัปเดตหรือไม่ |
| Settrade ไม่มีข้อมูล / ค้างเกิน `live.max_bar_lag_min` | ใช้ yfinance 1m แทน (บันทึก `data_source` ใน log) | ตรวจว่าแหล่งไหนถูกใช้ |
| ทุกแหล่งล้ม | baseline + ธง `fallback_reason` | กรอกมือได้ **เฉพาะก่อนส่ง** พร้อมแหล่งและเวลา |

⛔ **ห้ามกรอกราคาที่รู้ภายหลังแล้วนับเป็นคำทำนายทันเวลา**
ถ้าส่งซ้ำรอบเดียวกัน `06_score_live.py` นับรายการแรกเท่านั้น
