ส่งก่อน **09:30** (รอบเช้า) และ **12:30** (รอบบ่าย) ทุกวัน · ส่งด้วยโมเดลที่ล็อกเท่านั้น (ห้ามส่ง baseline / ผลรันเงา)

## ลำดับงานต่อวัน

| เวลา | คำสั่ง | ตรวจ |
|---|---|---|
| เย็นวันก่อน หลัง 17:00 | `python scripts/00_collect_daily.py` | จบด้วย "สำเร็จทั้งหมด" |

- [ ] วันนี้ไม่ใช่วันหยุดหรือวัน XD หรือปรับราคาอ้างอิงแล้ว (`data/external/calendar.csv` — 9–13 พ.ย. ไม่มีวันหยุดและไม่มี XD)
- [ ] รันตามจุดตัดที่วัดแล้ว ไม่ใช่ค่าชั่วคราว (`results/latency_2026-11-02.md`)
- [ ] `data_source` = settrade (รอบบ่าย)
- [ ] `fallback_reason` ว่าง หรือเข้าใจเหตุผลทุกบรรทัด
