## เทียบสองโมเดล (`bootstrap.py`) — ไฟล์ `bootstrap.csv`

- **block bootstrap รายวัน**: สุ่มซ้ำเป็นบล็อกวัน เก็บทุกหุ้นและรอบของวันเดียวกันไว้ด้วยกัน
- `mean_diff` = loss(variant ใหม่) − loss(ฐาน) → **ติดลบ = ใหม่ดีกว่า**
- `ci_low`–`ci_high` = ช่วง 95%; `prob_a_better` = สัดส่วนที่ใหม่ดีกว่า
- ไม่ใช้ binomial เทียบ 50% หรือ permutation รายแถว; คำนึงถึงการลองหลายแบบ [8]

> บริบทจากงานไทย: ทำนายทิศทาง SET index วันถัดไปได้ 49–53% เทียบสุ่ม 50.1% [13] → ใช้ตั้งความคาดหวัง **ไม่ใช่เป้าหมาย**

## เกณฑ์เลือก — ตามหลักฐาน ไม่ตามความซับซ้อน

- ทุกโมเดลใช้ labels ชุดทดสอบ และเวลาตัดเดียวกัน จูนภายในอดีตเท่านั้น
- รายงานผลทั้งสี่งาน (ทิศทาง, probability, ราคา, ช่วงราคา) ไม่รวมคะแนนกลบงานที่ยังแพ้ baseline
- ดูขนาดผล ความไม่แน่นอน และความเสถียร — ไม่เลือกด้วย p-value หรือ accuracy เดียว
- cascade / CNN ไม่ช่วย → ใช้แบบอิสระหรือโมเดลง่ายกว่า
- ยังไม่มีโมเดลชนะ baseline อย่างน่าเชื่อถือ → รายงานตามจริงและใช้ **baseline เป็น fallback**
- ถ้าจะนำไปเทรด ต้องประเมิน spread / ค่าธรรมเนียม / slippage แยกจากผลพยากรณ์
