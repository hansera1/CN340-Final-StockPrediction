| **7–8 พ.ย.** | ตรวจรุ่นโมเดล การโหลดข้อมูล ฟอร์แมตส่ง และแผนสำรอง | — | ☐ |

## แบ่งงาน

| หน้าที่ | ความรับผิดชอบ | โฟลเดอร์ / รหัส |
|---|---|---|
| **Data** | ข้อมูลดิบ คุณภาพ labels timestamp ความหน่วง ระบบวันจริง | `data/`, `src/forecast/data/`, `labels/`, `live/` · D1, D3, D4, D8 |
| **Features / EDA** | ตัวแปรที่รู้ทันเวลา flat spectrum ความละเอียด | `src/forecast/features/`, `feature_dictionary.csv` · D2, D7, D9 |
| **Modeling** | baseline, temporal OOF, cascade, CNN | `src/forecast/models/` · E1, E2, E4, E5, E6 |
| **Evaluation / Report** | folds กลาง metrics ablation ตารางผล สไลด์ | `src/forecast/evaluation/`, `outputs/experiments/` · E0, E3 |

ทุกคนใช้ชุดแบ่งข้อมูลและสคริปต์ประเมินเดียวกัน

**สิ่งส่งมอบ**: กติกากลาง · dataset/labels มีเวอร์ชัน · โค้ดทดลอง · โมเดลที่เลือกพร้อมเหตุผล · ตารางย้อนหลังแยกสี่งาน · log จริง 20 รายการ · รายงานพร้อมข้อจำกัด

**ก่อนเริ่ม**: ต้องได้ตัวอย่างไฟล์ ช่วงวันที่ คอลัมน์ แหล่งข้อมูล ความหน่วงจริง + คำตอบเรื่อง flat และราคา 16:30 + ขอบเขตโมเดลจากอาจารย์
