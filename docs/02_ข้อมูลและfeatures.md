### ตรวจข้อมูล (`01_check_data.py`)
นาทีขาด · ข้อมูลซ้ำ · ราคาผิดปกติ · volume สะสมแทนรายนาที · แยกนาทีไม่มีการซื้อขายออกจากนาทีที่ข้อมูลหาย
- ภาคบ่ายใช้ข้อมูล **หลัง 25 มี.ค. 2024** (ก่อนหน้านั้นเปิด 14:30)
- เก็บข้อมูลดิบแยกจากชุดปรับแล้ว; ข้อมูลหลังวันตัดฝึกต้องไม่ย้อนเข้าโมเดล

## Labels (`labels/make_labels.py`)

```
r_เช้า = log[ P(12:30) / P(10:00) ]     r_บ่าย = log[ P(16:30) / P(14:00) ]   → ทิศทาง
z      = log[ P(ปลายช่วง) / P(c) ]                                            → ราคา
ราคาที่คาด = P(c) × exp[ ẑ ]
```

- เก็บ ขึ้น / เท่าเดิม / ลง เสมอ (`direction` = 1 / 0 / −1)
- ขั้นทิศทางทำนาย **P(ขึ้น) ของทุกกรณี** — ไม่ใช่ P(ขึ้น | ไม่ flat)
- เน้น MAE → ทำนาย **median ของ z** แล้วแปลงกลับเป็น median ราคา
- แบบ gap หลายทอดเก็บไว้เป็นคู่แข่ง ไม่ใช่วิธีหลัก

## Features ตามเวลาที่ใช้จริง (`features/build.py`)

| กลุ่ม | รอบเช้า (ถึง c_เช้า) | รอบบ่าย (ถึง c_บ่าย) |
|---|---|---|
| ข้อมูลหุ้น | วันก่อนและแนวโน้มย้อนหลัง | + การซื้อขายวันนี้ถึงจุดตัด |
| ตลาดต่างประเทศ | เมื่อคืน + เอเชียถึงจุดตัด | ที่เผยแพร่แล้วถึงจุดตัด |
| การเปิดตลาดไทย | ยังไม่มี | ราคาเปิดเช้า + การเคลื่อนไหวหลังเปิด |
| Momentum / reversal | ผลตอบแทนวันก่อน + ช่วงเวลาเดียวกันในอดีต | ภาคเช้าถึงจุดตัด (ไม่ใช่ถึง 12:30) |
| ความผันผวน / ปริมาณ | จากอดีต | + สะสมก่อนจุดตัด |
| Gap พักเที่ยง | ไม่ใช้ | **ไม่ใช้** (ยังไม่รู้ P(14:00)) |

### หลักฐานจากเอเชีย
intraday momentum ในเอเชียอ่อนกว่าสหรัฐฯ [11] และข้ามประเทศไม่ได้แปลว่าทำกลยุทธ์ได้ทุกที่ [12] → **ทดสอบทั้ง momentum และ reversal** ไม่ตั้งสมมติฐานล่วงหน้า
