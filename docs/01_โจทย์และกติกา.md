# 01 โจทย์และกติกา

> แผนหัวข้อ 01–02 · ค่าที่ใช้จริงอยู่ใน [`configs/rules.yaml`](../configs/rules.yaml)

## โจทย์

| รอบ / หุ้น | กำหนดส่ง | เปรียบเทียบทิศทาง | ราคาที่ต้องทำนาย |
|---|---|---|---|
| เช้า: KBANK, ADVANC | 09:30 | P(12:30) เทียบ P(10:00) | P(12:30) |
| บ่าย: KBANK, ADVANC | 12:30 | P(16:30) เทียบ P(14:00) | P(16:30) |

- 1 วัน = 4 คำทำนาย → ครบ 5 วัน = **20 คำทำนาย** (พอสรุปสัปดาห์ ไม่พอยืนยันความเหนือกว่าระยะยาว)
- ผลภายในระบบเก็บ: probability ทิศทาง, ราคาจุดเดียว, ช่วง 50% และ 80%, ราคาอ้างอิงพร้อมเวลา, รุ่นข้อมูล, รุ่นโมเดล, สถานะการส่ง

## แยกเวลาตัดข้อมูลออกจากกำหนดส่ง

เวลาตัด **c_เช้า / c_บ่าย** ต้องเผื่อเวลารับข้อมูล ประมวลผล และส่ง → **ต้องวัดความหน่วงจริงก่อน**
ค่า 09:15 / 12:15 เป็นแค่ค่าตั้งต้น

| สถานะ | ข้อกำหนด |
|---|---|
| ✅ ยืนยันแล้ว | ส่ง 09:30 / 12:30; หุ้น KBANK / ADVANC; คู่ราคาตามโจทย์ |
| ❓ ต้องยืนยัน | 16:30 = ราคาสิ้นสุด continuous หรือราคาปิดประมูล; นับ flat อย่างไร; รูปแบบส่งและการปัด tick; ขอบเขตโมเดล (รวม pretrained) |
| 💡 ข้อเสนอหลัก | ใช้ราคาล่าสุดตามจุดเวลา; เก็บสามสถานะ (ขึ้น/เท่าเดิม/ลง); เก็บทั้งราคาสิ้นสุด continuous และราคาปิด |
| 🧪 ข้อเสนอการทดลอง | โมเดลสองขั้นเป็นงานหลัก, CNN เป็นคู่แข่ง |

## รู้อะไร / ยังไม่รู้อะไร ณ เวลาตัดข้อมูล

| รอบ | รู้แล้ว | ยังไม่รู้ (ห้ามใช้) |
|---|---|---|
| **เช้า** (c ≤ 09:30) | ราคาและปริมาณถึงวันก่อน, ราคาปิดเมื่อวาน, ตลาดสหรัฐฯ คืนก่อน, ค่าเงิน, ตลาดญี่ปุ่นและฮ่องกง/จีนถึงจุดตัด, ฟลอว์วันก่อนที่เผยแพร่แล้ว | ราคาเปิดวันนี้, P(10:00), P(12:30), ราคาประมูลช่วง pre-open |
| **บ่าย** (c ≤ 12:30) | ทุกอย่างของรอบเช้า + ราคาเปิดเช้าจริง, การซื้อขายวันนี้ถึงจุดตัด, ตลาดเอเชียถึงจุดตัด | แท่งที่ยังไม่จบ, ช่วงหลังจุดตัดถึง 12:30, gap พักเที่ยง, P(14:00), P(16:30), ฟลอว์เต็มวันของวันนี้ |

⚠️ **P(10:00) / P(14:00) ใช้เป็นคำตอบย้อนหลังได้ ห้ามเป็น feature** — ราคาเปิดสุ่มก่อนจุดเวลา (09:55–10:00, 13:55–14:00) ส่วน 16:30 คือจุดสิ้นสุด continuous ไม่ใช่เวลาประมูลปิด

## กติกาการใช้ราคา (โค้ด: `src/forecast/data/asof.py`)

- ใช้เฉพาะแท่งที่ **จบแล้ว** และข้อมูลมาถึงแล้ว
- ไม่มีรายการตรงเวลา → ใช้รายการล่าสุดที่ผ่านเกณฑ์พร้อมอายุราคา **ไม่ใช้รายการถัดไปเติมย้อนกลับ**
- timestamp ใช้ Asia/Bangkok และต้องระบุว่าเป็นเวลาเริ่มหรือจบแท่ง (`bar_timestamp`)
- ใช้วิธีเดียวกันทั้ง train / test / live
