## ส่วน 1: oracle

| แบบ | ราคาจุด |
|---|---|
| PR-A | กฎราคาเดิม เริ่มจาก P(c) |
| Oracle-rule | ความน่าจะเป็นเดิม แต่เริ่มจาก P(10:00) จริง |
| H2b-rule | ผล E18b เริ่มจาก P(c)′ ที่ปรับด้วย gap ที่ทาย |
| P(10:00) | ใช้ P(10:00) จริงเป็นราคาคาดตรง ๆ |

รายงาน MAE และ RMSE พร้อมผลต่างเทียบ PR-A และ CI 95% แบบ bootstrap รายวัน · **Oracle ใช้ราคาที่ยังไม่รู้ตอนส่ง จึงเป็นเพดานเชิงทฤษฎี ใช้จริงไม่ได้** · รายงาน correlation ของ ĝ กับ gap จริงแยกหุ้น และผล E18 H2 เดิม

**ตีความที่กำหนดล่วงหน้า:** ถ้า oracle ลด MAE มาก gap เป็นตัวการใหญ่ และคุ้มที่จะหา feature เพิ่ม · ถ้าลดน้อย ปัญหาหลักอยู่ที่การขยับระหว่างรอบ
