## 1. ข้อมูลและการแบ่งเวลา

dataset และ feature เดียวกับ E14: `load_or_build_dataset(rules, as_of=WF_LAST_DAY 29 ต.ค., tag="_wf")` · `aligned()` จาก `31_e14_finetune.py` · ป้าย up_notup = `direction == 1` รวมวันนิ่ง · ทดสอบ walk-forward บล็อก 5 วันถึง 12 ต.ค. 2026 ด้วย `walk_forward_splits` และ `min_train_days` เดิม แยกรอบ

ทุกบล็อกทดสอบ ใช้เฉพาะวันที่มีป้ายและอยู่ก่อนวันแรกของบล็อก:

```text
ud  = วันทำการที่ไม่ซ้ำ รวมทั้งสองรอบ เรียงตามเวลา
cut = floor(0.70 × len(ud)) · gap = 5 วันทำการ
pre = ud[: cut − 5]   รวมสองหุ้น สองรอบ + dummy หุ้น + dummy รอบ
ft  = ud[cut :]       เฉพาะแถวของรอบที่กำลังฝึก
```

ต้องเป็นจริงทุกบล็อก: max(pre) < min(ft), max(ft) < min(test) และไม่มีวันซ้อนกัน

## 2. แบบที่เทียบ

| ชื่อ | pretrain | fine-tune | บทบาท |
|---|---|---|---|
| **D-prime** | `pre` | `ft` ของรอบนั้น · เลือก κ ด้วย inner CV ภายใน `ft` | แบบหลัก |
| **Pre70** | `pre` | ไม่ fine-tune (κ = ∞) | แยกผลของ fine-tune ออกจากการใช้ข้อมูลน้อยลง |
| **D** | ผลเดิมของ E14 (`outputs/experiments/E14/d_predictions.csv`) | ซ้อนกับ pretrain | ตัวเทียบ |
| **A-un** | `outputs/experiments/E16/a_un_predictions.csv` | – | ตัวเทียบที่ใช้ตัดสิน |
| **E0-un** | `e0_window` ของ `30_e16_up_notup.py` | – | ตัวเทียบที่ใช้ตัดสิน |
| **A-ud** | `s18.load("C1235", "E12_fd_lr", tz)` | – | รายงานเท่านั้น |
| **E15 MLP** | `outputs/experiments/E15/predictions.csv` (มีอยู่) รอบบ่าย | – | รายงานเท่านั้น ไม่รันใหม่ |

**Sensitivity (รายงานเท่านั้น):** D-prime แบบ 60/40 และ 80/20

## 3. การ fine-tune

กรอบเดียวกับ E14 ผ่าน subclass ของ `PretrainFineTune` โดยไม่แก้ class เดิม:

- pre_cols = shared + `d_sess_pm` + `d_sym_advanc` · ft_cols = shared + `d_sym_advanc` + `f_gap_open`, `f_rv_intra` เมื่อเป็นรอบบ่าย · const = `d_sess_pm`
- C และ scaler เลือกจาก `pre` เท่านั้น · κ ∈ {0.3, 1, 3, 10, 30, ∞} · λ = κ / (2C) · intercept อิสระ
- `ft` < 40 วัน → κ = ∞ · < 60 วัน → κ = 10 คงที่ · อื่น ๆ เลือกด้วย inner CV ภายใน `ft`
- bag เฉพาะ fine-tune 20 รอบ บล็อก 20 วัน seed เดิม
- **แก้ใน subclass:** scaler ของ feature เฉพาะบ่ายในแต่ละ fold ของ inner CV fit จากแถว `ft` ก่อน `cut` ของ fold นั้นเท่านั้น (class เดิม fit จาก `ft` ทั้งก้อน)

**ช่วงตัดสิน (common window):** เฉพาะบล็อกที่รอบนั้นมี `ft` ≥ 40 วัน และ `pre` มีทั้งเช้าและบ่ายอย่างละ ≥ 40 วัน · เทียบทุกแบบบนแถวเดียวกัน · รายงานบล็อก วัน และแถวที่ถูกตัดออก

## 4. เกณฑ์ตัดสิน (แยกเช้าและบ่าย · block bootstrap รายวัน 2,000 ครั้ง · CI 99.7%)

D-prime **ผ่านในรอบนั้น** เมื่อครบทุกข้อ เทียบกับทั้ง A-un และ E0-un:

1. ผลต่าง log loss (D-prime − ตัวเทียบ): ขอบบน < 0
2. ผลต่าง `acc_up_notup`: ขอบบน ≥ 0
3. แยกรายหุ้น: ผลต่าง log loss ขอบล่าง ≤ 0 ทุกหุ้น

**ไม่ผ่าน ≠ ไม่มีผล** · ถ้าผ่านก็ถือเป็นสมมติฐาน เพราะข้อมูลชุดนี้ถูกทดสอบซ้ำมาตั้งแต่ E9

**คำถามเชิงกลไก (CI 95% · ไม่ใช่เกณฑ์ผ่าน):** D-prime − Pre70 · D-prime − D · Pre70 − A-un
