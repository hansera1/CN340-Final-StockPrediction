## แนวคิด

- ชั้น 1 = E12 `fd_lr` ที่ล็อก (ข้อมูล ~2.5 ปี ไม่เปลี่ยน)
- ชั้น 2 = ปรับ P(ขึ้น) ของชั้น 1 เล็กน้อยด้วย feature 5m ของภาคเช้าวันนี้ ฝึกด้วย 20 วันทำการล่าสุด
- **รอบบ่ายเท่านั้น** ไม่แตะรอบเช้าและโมเดลราคา

## โมเดลชั้น 2 (ล็อก)

- logit(p_final) = logit(p₁) + β₁x₁ + β₂x₂ + β₃x₃
- logit(p₁) เป็น offset (สัมประสิทธิ์ตรึง 1) · ไม่มี intercept
- x standardize ด้วย mean / sd ของชุดฝึกของวันนั้นเท่านั้น
- L2: ลงโทษ (λ/2)·‖β‖² บน log-likelihood รวม (ผลรวม ไม่ใช่ค่าเฉลี่ย) **λ = 45 ค่าตายตัว ไม่จูน**
  (prior SD ≈ 1/√45 ≈ 0.15 ต่อ 1 SD ของ feature; p₁ อยู่ใกล้ 0.5 โดย |logit(p₁)| ราว 0.1 และชุดฝึกมีราว 30 แถวไม่ flat
  ถ้า λ เล็ก ชั้น 2 จะพลิกทิศทางชั้น 1 บ่อยแม้ไม่มีสัญญาณ) · แก้ด้วย L-BFGS
- pooled สองหุ้น β ชุดเดียว · เป้าหมาย ขึ้น vs ลง บนวันไม่ flat · ตัดสิน p_final ≥ 0.5 → ขึ้น

## Feature 5m (3 ตัว ล็อก)

จากแท่ง 5m ภาคเช้าของวันนั้นที่ bar_end ≤ จุดตัด ไม่ใช้แท่งที่เริ่มก่อน 10:00 ใช้ราคาอย่างเดียว · P_cut = ราคาปิดแท่ง 5m ล่าสุดที่จบ ≤ จุดตัด

- `f5_r_last15` = log(P_cut / P_(cut−15 นาที)) — P_(cut−15) = ราคาปิดแท่งล่าสุดที่จบ ≤ จุดตัด − 15 นาที (as-of ไม่เติมย้อนกลับ;
  ไม่มีแท่งที่จบ ≤ เวลานั้นในภาคเช้า → ใช้ open ของแท่งแรก)
- `f5_close_vs_twap` = log(P_cut / ค่าเฉลี่ยราคาปิดแท่ง 5m ตั้งแต่ 10:00 ถึงจุดตัด) (TWAP — volume ภาคเช้าของ yfinance เสีย)
- `f5_range_pos` = (P_cut − L) / (H − L) จาก high / low ของแท่ง 5m ภาคเช้า (H = L → 0.5)
- แหล่ง: backtest = yfinance 5m · วันจริง = Settrade 1m รวมเป็น 5m ด้วย `aggregate_bars(bars, 5, rules)`

## E-2 ตรวจแหล่งข้อมูล (ต้องผ่านก่อนใช้วันจริง)

วันที่มีทั้ง Settrade 1m และ yfinance 5m: รวม Settrade 1m เป็น 5m เทียบ OHLC ทุกแท่งภาคเช้า และเทียบ f5_* ณ จุดตัด
ผ่าน = ราคาต่างไม่เกิน 1 ช่อง ≥ 95% ของแท่ง **และ** f5_* เครื่องหมายตรงกันทุกวัน
(f5_range_pos ไม่มีเครื่องหมาย → เทียบว่าอยู่ฝั่งเดียวกันของ 0.5)

## E-3 Backtest (รันครั้งเดียว)

- วันทดสอบ: มี 5m ภาคเช้าครบ + p₁ out-of-sample + มีวันฝึกครบ 20 วัน — รายงานจำนวนวันและรอบไม่ flat จริง
- ตัวเทียบ: **S1** (ชั้น 1 อย่างเดียว, ตัวเทียบหลัก) · **S12** (ชั้น 1 + 2) · **E0-ud** · **S12-placebo** (ชั้น 2 ที่ใช้ f5_* ของวันทำการก่อนหน้า ทั้งฝึกและทาย)
- ตัวชี้วัด: หลัก = log loss ขึ้น/ลง · รอง = ความแม่นไม่นับ flat และ flat = ผิด
  · อธิบาย = สัดส่วนรอบที่ชั้น 2 พลิกทิศทาง, ความแม่นเฉพาะรอบที่พลิก, β รายวัน, ค่าเฉลี่ย |p_final − p₁|
- CI: block bootstrap รายวัน 2,000 ครั้ง แบบจับคู่วันเดียวกัน

## E-4 เกณฑ์ตัดสิน (ล็อก) — S12 ส่งจริงรอบบ่ายเมื่อผ่านครบทุกข้อ

1. Δ log loss (S12 − S1) < 0 และขอบบนของ CI 95% < 0
2. Δ ความแม่นไม่นับ flat ≥ 0
3. ไม่มีหุ้นใดที่ S12 แย่กว่า S1 อย่างมีนัยสำคัญ (log loss หรือความแม่น, CI ไม่ครอบ 0 ฝั่งแย่)
4. S12 ดีกว่า S12-placebo (Δ log loss < 0)
5. ผ่าน E-2
6. สัดส่วนรอบที่ชั้น 2 พลิกทิศทาง ≤ 20%

- ไม่ผ่านข้อใด → ส่ง S1 และรัน S12 แบบเงา
- ข้อยกเว้น: ถ้าอาจารย์ตอบชัดว่าต้องการให้ตัวส่งจริงใช้ข้อมูลช่วงสั้น ใช้ S12 ส่งจริงได้แม้ไม่ผ่านข้อ 1–4
  แต่ต้องผ่านข้อ 5 และ 6 และระบุในรายงานว่าเลือกตามกติกา ไม่ใช่เพราะผลดีกว่า
