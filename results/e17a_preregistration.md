## แบบที่เทียบ

| แบบ | นิยาม |
|---|---|
| **PR-D** | A-price (`flat_price`) และ p_price (`price_updown`) pretrain รวมสองหุ้นสองรอบ แล้ว fine-tune แยกรอบ · ใช้กฎค่ามัธยฐานเดิม |
| **PR-D+C** | fine-tune ด้วยแถวช่องราคา 1 บาท ขั้นต่ำ 40 วันนับจาก KBANK |
| **PR-mean** | ความน่าจะเป็นจาก A-price / p_price LR เดิม (`outputs/experiments/C1235/`) + สูตร `decimal_point` เดิม: P(c)·exp(P(สูงกว่า)·E[z\|สูงกว่า] + P(ต่ำกว่า)·E[z\|ต่ำกว่า]) · E[z\|·] แยกหุ้น/รอบ จากวันก่อนวันที่ทาย · รายงานทั้งไม่ปัดและปัดช่อง · แบบที่เข้าข้อ 9 = ไม่ปัด |
| **PR-A** | ตัวเทียบ: กฎค่ามัธยฐานเดิมบน C1235 |
| **P(c)** | ตัวเทียบ: ราคาจุด = P(c) |
| PR-C′ | เพื่อนเป็นผู้ทำ · นับใน Bonferroni แม้ไม่เสร็จ |

## เกณฑ์ (รายงาน — ตัวตัดสินจริงคือข้อ 9)

CI Bonferroni **98.75%** (นับ 4 แบบ) · แยกรอบ รวมสองหุ้น และรายงานแยกหุ้นเป็นหลัก · ผลต่าง = แบบนั้น − PR-A · MAE ใช้ค่าเฉลี่ยผลต่างรายวัน · RMSE คำนวณใหม่จากวันที่สุ่มได้ของแต่ละแบบ (จับคู่วันเดียวกัน) แล้วลบกัน

**ผ่าน** เมื่อครบทุกข้อ:
1. MAE หรือ RMSE ต่ำกว่า PR-A: ขอบบนของ CI < 0 ในช่วงหลัก (PR-D, PR-mean = ทั้งช่วง · PR-D+C = แถวช่องราคา 1 บาท)
2. อีกตัวชี้วัดในช่วงหลัก: ขอบล่างของ CI ≤ 0 (ไม่แย่กว่าอย่างมีนัยสำคัญ)
3. ทั้ง MAE และ RMSE ในอีกช่วง: ขอบล่างของ CI ≤ 0
4. coverage: |coverage − เป้า| ของช่วง 50% และ 80% ไม่มากกว่า PR-A (ใช้กับแบบที่ปัดช่อง)

**ตัวแทนเข้าข้อ 9:** แยกช่องราคาเช้า/บ่าย · PR-D กับ PR-D+C เลือกจาก inner-CV log loss รวมของ A-price + p_price บนบล็อกร่วม ไม่ดูผลชุดทดสอบ · PR-mean เป็นตัวเลือกแยกของข้อ 9 ตามแผน

## รายงานเพิ่ม

MAE / RMSE แยกหุ้นและรอบ · สัดส่วนรอบที่เลื่อนและเลื่อนถูกทาง · ความแม่นตรงช่อง · log loss ของ A-price / p_price · coverage และความกว้างของช่วง 50% / 80% · quantile จากทุกแถวเทียบเฉพาะแถวช่องราคา 1 บาท · κ ที่ถูกเลือก
