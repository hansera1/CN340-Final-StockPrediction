## ตัวชี้วัด

- **XIRR:** กระแสเงินสด −เงินลงทุนในวันแรก, กำไรขาดทุนสุทธิรายวัน และ +เงินลงทุนในวันสุดท้าย · แก้ Σ CFᵢ / (1 + r)^((dᵢ − d₀)/365) = 0 ด้วย `scipy.optimize.brentq` · ตรวจกับสูตรเดียวกันในตัวอย่างเล็กที่คำนวณด้วยมือ (Excel ไม่มีให้เรียกจากสคริปต์)
- **Sharpe ratio รายปี:** (ค่าเฉลี่ยผลตอบแทนรายวัน − rf รายวัน) / SD รายวัน × √252 · ผลตอบแทนรายวัน = กำไรขาดทุนรายวันรวมทุกช่อง / เงินลงทุนรวม · วันที่ไม่ลงทุน = 0 · rf = อัตราดอกเบี้ยนโยบาย ธปท. 1.00% ต่อปี (คงที่ตลอดปี 2569) / 252 และรายงาน rf = 0 คู่กัน
- เสริม: ผลตอบแทนสะสม, max drawdown, จำนวนครั้งที่ซื้อขาย, อัตราชนะ
- **CI ของ Sharpe** และ **ผลต่าง Sharpe (S1 − B1)**: block bootstrap รายวัน 2,000 ครั้ง · CI 95% · มีนัยสำคัญเมื่อ CI ไม่ครอบศูนย์

**รายงาน:** walk-forward, holdout และส่งจริง (ถ้ามี) แยกรอบและรวม · equity curve ของ S1 เทียบ B1 และ B2 (walk-forward)
