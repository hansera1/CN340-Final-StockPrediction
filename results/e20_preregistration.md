# E20 — ลงทะเบียนเกณฑ์ล่วงหน้า (แก้ overfit ทุกกลุ่ม · เจ้าของโปรเจกต์สั่ง 7 พ.ย. 2026)

**commit ก่อนรัน · ห้ามแก้ส่วนบนหลังเห็นผล** · กติกา: `results/decision_rules.md` · ที่มา: `results/overfit_report.md` · โค้ด: `experiments/43_e20_antioverfit.py`

**เห็นผลการทดลองก่อนหน้าแล้ว** จึงเป็นการทดลองหลังเห็นผลบนข้อมูลชุดเดิม โอกาสบังเอิญสูงกว่า E14–E17

ข้อมูล: dataset ATC + 12:35, `as_of` 29 ต.ค., tag `_wf` · walk-forward บล็อก 5 วัน ถึง 12 ต.ค. · **ไม่ใช้ holdout** · ไม่จูนด้วย Optuna

## วิธีแก้ตามสาเหตุ

| สาเหตุที่พบ | วิธีแก้ |
|---|---|
| โมเดลจำข้อมูลฝึก | regularization แรงขึ้น โมเดลตื้นลง และ feature น้อยลง |
| เลือกแบบเกินจริง (PBO สูง) | ค่าตายตัว ไม่จูน และกำหนดตัวแทนล่วงหน้า |
| ค่าความน่าจะเป็นแกว่ง | เฉลี่ยหลายโมเดล และดึงเข้าหาสถิติพื้นฐาน |
| CNN overfit เร็ว | ตรึง backbone หรือลด learning rate พร้อม early stopping เร็ว |

## แบบตาราง (ทิศทาง up_notup, ราคา flat_price + price_updown)

ใช้ feature ชุดเดิมของ E15 / E17b · fit ใหม่ทุกบล็อก · pooled สองหุ้น แยกรอบ

| แบบ | ค่าตายตัว |
|---|---|
| lr | C = 0.001 |
| lr_k10 | C = 0.003 · 10 feature ที่ |correlation| สูงสุดในข้อมูลฝึก |
| enet | C = 0.01, l1_ratio = 0.5 |
| svm | C = 0.001 |
| rf | 200 ต้น, ลึก 2, ใบ ≥ 100, max_features 0.3 |
| mlp | 1 ชั้น 4 โหนด, alpha = 30 |
| lgbm, xgb | 60 ต้น, lr 0.02, ลึก 2, ใบ ≥ 100, subsample 0.6, colsample 0.4, L2 = 20 · รายงานเท่านั้น เพราะ VM ไม่ได้ติดตั้ง |
| ENS | เฉลี่ยเท่ากัน: lr, lr_k10, enet, svm, rf, mlp |
| **SHR** | 0.5 × ENS + 0.5 × สัดส่วนในข้อมูลฝึก แยกหุ้น |
| A-ud-strong | A-ud เป้าหมาย updown, C = 0.001 ไม่ bag · ตัดสิน ≥ 0.5 |

## แบบอื่น

- **E14 / E17a:** D และ PR-D ด้วย κ = 30 ตายตัว (ดึงเข้าหาโมเดล pretrain แรง) · C′, C-adv, PR-C′ ไม่รันซ้ำ เพราะส่วนใหญ่เป็น κ = ∞ อยู่แล้ว
- **E10 CNN:** ตรึง backbone 5 สถาปัตยกรรม → StandardScaler → PCA 10 ตัว fit บนข้อมูลฝึก → LR C = 0.01 · เป้าหมาย up_notup บนภาพ 60m ของ dataset นี้
- **E10 fine-tune:** ResNet18 S2 เท่านั้น: 1 seed, ≤ 10 epoch, patience 2, lr หัว 3e-4, lr block 3e-5, weight decay 0.2, บล็อก 20 วัน · **S2/S3 ที่เหลือและ x20 ไม่รันซ้ำ** เพราะชุดเดิมใช้รวมประมาณ 520 ชม.
- **E19:** S0 λ = 200, S0-LR C ∈ {0.0003, 0.001}, S1/S2 ค่าเดียวกับ ResNet18 S2 ด้านบน · รันสำรวจ 8 + 6 วัน ทั้ง 1m และ 5m
- **ไม่รัน:** E13 (backtest ไม่ได้ทำ), E18 (ไม่มีการเลือกหลายแบบ)

## ตัวแทนและการตัดสิน (ตามข้อ 9 ของกติกา)

**ตัวแทนกำหนดล่วงหน้า ไม่เลือกจากผล: SHR ทั้ง 4 ช่อง** เพราะเป็น scikit-learn ล้วน และไม่ต้องเลือกโมเดล

- CI 99.7% · ทิศทางเทียบ A-ud (ค่าตั้งต้น) และรายงานเทียบ E15 MLP กับ E0-un · ราคาเทียบ PR-A
- **ทิศทางผ่าน:** ผลต่าง log loss ขอบบน < 0 และผลต่างความแม่นขอบบน ≥ 0 และไม่แย่กว่าในหุ้นใดหุ้นหนึ่ง
- **ราคาผ่าน:** MAE หรือ RMSE ขอบบน < 0 อีกตัวขอบล่าง ≤ 0 และไม่แย่กว่าในหุ้นใดหุ้นหนึ่ง
- CNN, LightGBM, XGBoost และ fine-tune เข้าข้อนี้ไม่ได้ เพราะ VM ใช้ไม่ได้หรือไม่ทันทดสอบ · รายงานเท่านั้น
- ผลต้องครบก่อนอาทิตย์ 8 พ.ย. 12:00 · **เจ้าของโปรเจกต์ตัดสินก่อนอาทิตย์ 18:00 · ห้ามสลับเอง** · ล็อก ซิงก์ VM และซ้อมให้เสร็จภายใน 22:00 ไม่ทันใช้ของเดิม
- หลังรอบแรกวันจันทร์ ห้ามเปลี่ยนจนจบ 13 พ.ย.
