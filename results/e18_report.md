## H1: เงื่อนไขทิศสัมประสิทธิ์ไม่ผ่าน และตรวจบั๊กแล้วไม่พบ

ค่าเฉลี่ยสัมประสิทธิ์: `fx_spx` ADVANC −0.011 · `fx_n225_gap` KBANK −0.027 (ที่เหลือบวก) ตรวจแล้วก่อนรัน H2/H3:
- ทีละ feature ทุกตัวมีทิศตามคาดทั้งสองหุ้น (correlation 0.19–0.34, `fx_usdthb` ติดลบ −0.16 ถึง −0.20)
- ความสัมพันธ์สูงสุดอยู่ที่วันที่ถูกต้อง เลื่อนวัน ±1 แล้วใกล้ 0 จึงไม่พบการจับคู่วันผิด
- วันจันทร์ใช้ราคาปิด S&P ของวันศุกร์ (เช้าวันเสาร์เวลาไทย) ถูกต้อง · วันหยุดญี่ปุ่น `fx_n225_gap` เป็นค่าว่าง
- สัมประสิทธิ์ที่ติดลบอธิบายได้จาก feature ซ้ำซ้อน: Nikkei กับ KOSPI 0.69, S&P กับ Nikkei 0.52

เงื่อนไขที่ลงทะเบียนไว้ไม่ได้ถูกแก้ จึงรายงานว่าไม่ผ่าน และรัน H2/H3 ต่อเพราะตรวจบั๊กครบแล้ว
