**commit ก่อนรัน (7 พ.ย. 2026)** · โค้ดตั้งต้นของเพื่อน: `experiments/25_1m_scalogram_demo.py`, `26_train_1m_cnn.py` → เปลี่ยนเลขเป็น `27_`, `28_` และแก้ตามแผนรอบ 7 ข้อ 10 · flow: `docs/08_cnn_1m_flow.md`

## ข้อมูล

Settrade 1m + yfinance 1m (วันที่ Settrade ไม่มี) · ยกเว้นจาก `as_of` ใช้ช่วง holdout และหลัง holdout ได้ เพราะไม่ใช้ตัดสิน · dataset tag `_e19`
ขั้นต่ำฝึก 20 วัน · วันทดสอบ < 5 วัน = รายงานว่าวัดผลไม่ได้

## ตัวอย่างและป้าย

1 ภาพต่อ (หุ้น, วัน) · input = แท่ง 1m 10:00–12:30 ของวันนั้น ห้ามใช้แท่งหลัง 12:30 · แท่งจริงอย่างน้อย 120 จาก 150 นาที · ป้าย = รอบบ่ายตาม `rules.yaml` (ราคาปิดทางการรวม ATC เทียบ P(14:00)), ขึ้น/ไม่ขึ้น

## ภาพ

224×224, 3 ช่อง (r, |r|, log volume) · Morlet ω₀ = 6, 32 scale, s = 2 ถึง n/2 แท่ง (เริ่มที่ Nyquist) · log1p → 0–1 · normalize ImageNet mean/std

## โมเดล

3 สถาปัตยกรรม (ResNet18, VGG16-BN, DenseNet121) × S0, S0-LR, S1, S2 = 12 แบบ · ไม่ทำ S3 · สเปกการฝึกเดียวกับ E10 · 3 seed · walk-forward ฝึกใหม่ทุกวัน · early stopping ใช้ส่วนท้ายของข้อมูลฝึกเท่านั้น

| วิธี | รายละเอียด |
|---|---|
| S0 | เวกเตอร์ (512 / VGG fc7 4096 / 1024) → PCA fit บนข้อมูลฝึก 3 และ 5 ตัว → ชั้น 2 offset บน A-un, λ = 45 ตายตัว |
| S0-LR | เวกเตอร์เต็ม → StandardScaler → LR, C จาก {0.003, 0.01, 0.03, 0.1} บนส่วนท้ายของข้อมูลฝึก |
| S1 | หัวใหม่ GAP → dropout 0.5 → linear |
| S2 | หัว + block สุดท้าย |

**Model B:** z = ln(ราคาปิดทางการ / P(c)) ด้วย LinearRegression บน out-of-fold probability ของ Model A (ตัดตามวัน 4 fold) · รายงาน MAE / RMSE เทียบ P(c)
**A-un สำหรับชั้น 2:** walk-forward รายวันบน dataset `_e19`

## ผลที่ได้

สำรวจเท่านั้น รายงานจำนวนตัวอย่างและความกว้าง CI · ไม่ส่งเข้าข้อ 9 · `--smoke` ใช้ตรวจ pipeline เท่านั้น ห้ามอ้างเป็นผล

## ข้อแก้จากโค้ดตั้งต้น

ไม่สร้าง `conv1` ใหม่ (เดิมทิ้งน้ำหนัก ImageNet ชั้นแรก) · เลิกหน้าต่างเลื่อนและ horizon 15 นาที · ไม่แบ่ง sample ในวันเดียวกัน · ไม่ใช้วัน valid เลือก epoch แล้ววัดผลบนวันเดียวกัน · Model B ไม่ใช้ความน่าจะเป็น in-sample
