## feature (5 ตัว เฉพาะรอบเช้า) · หน้าต่างข้ามคืนของวันไทย D = (16:30 วันทำการไทยก่อนหน้า, 08:30 วัน D]

| ชื่อ | นิยาม |
|---|---|
| `fx_spx` | ln การเปลี่ยนแปลงของ `^GSPC` Close ในหน้าต่าง |
| `fx_thd_prem` | ln การเปลี่ยนแปลงของ `THD` Adj Close − ln การเปลี่ยนแปลงของ SET50 + ln การเปลี่ยนแปลงของ `THB=X` ในหน้าต่าง |
| `fx_n225_gap` | ln(Open `^N225` วัน D) − ln(Close ล่าสุดก่อนวัน D) · ไม่มี Open วัน D = ค่าว่าง |
| `fx_kospi_gap` | เหมือนข้างบน ด้วย `^KS11` |
| `fx_usdthb` | ln การเปลี่ยนแปลงของ `THB=X` (60m ถ้ามี ไม่งั้นรายวัน) |

timestamp: ใช้เวลาจริงตามตลาดแปลงด้วย `zoneinfo` · สหรัฐ Close 16:00 New York · Nikkei Open 09:00 Tokyo, Close 15:30 · KOSPI Open 09:00 Seoul, Close 15:30 · SET50 Close 16:40 Bangkok · THB=X รายวัน ถือว่าพร้อมใช้ 00:00 UTC ของวันถัดไป (ระวังการรั่ว) · 60m ใช้เวลาจบแท่ง
SET50 รายวัน: ใช้ Yahoo `^SET50` (ไม่มีไฟล์ Settrade) และรายงานเป็นความต่างจากแผน · ข้อมูลเก็บที่ `data/raw/external/` ไม่อยู่ใน `data/external/` เพื่อไม่ให้เข้าระบบ live

## การทดลอง (dataset ATC + 12:35, `as_of` 29 ต.ค., tag `_wf` · walk-forward ถึง 12 ต.ค.)

**H1 ตัวตรวจระบบ:** regression เชิงเส้นของ gap = ln(P(10:00)/ราคาปิดทางการวันก่อน) ด้วย 5 feature แยกหุ้น walk-forward · คาดว่าสัมประสิทธิ์ `fx_spx`, `fx_n225_gap`, `fx_thd_prem` เป็นบวก และ correlation นอกตัวอย่างเป็นบวกชัดเจน (ขอบล่าง CI 95% > 0) · **ไม่เป็นตามคาด = หยุดและหาบั๊กก่อนทำ H2/H3**

**H2 ราคาเช้า:** ฐาน PR-A · p_price เพิ่ม 5 feature · A-price เพิ่ม |`fx_spx`|, |`fx_n225_gap`| · CI 95% block bootstrap รายวัน 2,000 ครั้ง · **ผ่าน:** ผลต่าง MAE รวมรอบเช้า ขอบบน < 0 และไม่มีหุ้นใดแย่ลงอย่างมีนัยสำคัญ

**H3 ทิศทางเช้า (ขึ้น/ไม่ขึ้น):** ฐาน A-un (E16) · เพิ่ม 5 feature ไม่เปลี่ยนอย่างอื่น · **ผ่าน:** ผลต่าง `acc_up_notup` CI ไม่ครอบ 0 และเป็นบวก, ไม่มีหุ้นใดแย่ลงอย่างมีนัยสำคัญ, log loss ไม่แย่ลง · รายงานเทียบ A-ud และ E0-un ด้วย

ข้อจำกัด: ทดลองเพิ่มจากที่ทำมาแล้วจำนวนมาก โอกาสเจอผลดีโดยบังเอิญสูงขึ้น · ไม่ปรับเกณฑ์หลังเห็นผล
