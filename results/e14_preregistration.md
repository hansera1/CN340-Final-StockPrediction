## แบบที่เทียบ

| แบบ | pretrain | fine-tune |
|---|---|---|
| **D** | รวมสองหุ้น สองรอบ + dummy รอบ + dummy หุ้น | แยกรอบ ด้วยแถวรอบนั้นทั้งหมด |
| **D+C** | เหมือน D | แยกรอบ ด้วยแถวช่องราคา 1 บาท (`tick_size(P(c)) = 1`) · ขั้นต่ำ 40 วันนับจากแถว KBANK |
| C′, C-adv | เพื่อนเป็นผู้ทำ | นับใน Bonferroni แม้ไม่เสร็จ |
| **A-un** | ตัวเทียบ (E16) | |

**จัด feature ตามลำดับเวลา:** `t_r_prev1` = เช้า `f_r_prev_afternoon` / บ่าย `f_r_open_to_cut` · `t_r_prev2` = เช้า ผลตอบแทนภาคเช้าวันก่อน / บ่าย `f_r_prev_afternoon` · feature เฉพาะบ่าย `f_gap_open`, `f_rv_intra` เริ่มที่ β₀ = 0 · ที่เหลือใช้ชุด F0 + F-daily + วันในสัปดาห์เหมือน `fd_lr`

## กรอบ fine-tune

loss = Σ log loss + λ‖β − β₀‖² · λ = κ / (2·C_pretrain) · κ ∈ {0.3, 1, 3, 10, 30, ∞} · scaler จาก pretrain · intercept อิสระ · dummy คงที่ตัดออกและรวมเข้า intercept เริ่มต้น · pretrain 1 ครั้ง, bag fine-tune 20 รอบ บล็อก 20 วัน · ข้อมูล fine-tune < 40 วัน → κ = ∞ · < 60 วัน → κ = 10 คงที่ · อื่น ๆ เลือก κ ด้วย inner CV แบบขยาย 3 fold ละ ≥ 10 วัน โดย pretrain ซ้ำใน fold

## เกณฑ์ (รายงาน — ตัวตัดสินจริงคือข้อ 9)

CI Bonferroni **98.75%** (นับ 4 แบบ) แยกรอบ เทียบ A-un ด้วยเกณฑ์ทิศทาง: log loss ขอบบน < 0 และผลต่าง `acc_up_notup` ขอบบน ≥ 0

- **D:** ชนะบนทั้งช่วง และไม่แย่กว่าในแถวช่องราคา 1 บาท (ขอบล่างของผลต่าง log loss ≤ 0)
- **D+C:** ชนะในแถวช่องราคา 1 บาท และไม่แย่กว่าบนทั้งช่วง
- **"ไม่ผ่าน ≠ ไม่มีผล"** แถว KBANK ช่องราคา 1 บาทมี ~95 วันต่อรอบ CI กว้าง ±7–10 จุด · D+C ส่วนใหญ่จะเป็น κ = ∞ ก่อน KBANK มี 40 วัน จึงผ่านเงื่อนไข "ไม่แย่กว่า" ได้ด้วยโครงสร้าง

**ตัวแทนเข้าข้อ 9:** แยกช่องทิศทางเช้า/บ่าย เลือกแบบที่ inner-CV log loss เฉลี่ยต่ำกว่า บนแถว validation ทั้งหมดของรอบนั้น ไม่ดูผลชุดทดสอบ
