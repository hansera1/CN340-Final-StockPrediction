# E23 — ลงทะเบียนเกณฑ์ล่วงหน้า (CNN+ANN + skip ราคาอ้างอิง + feature ต่างประเทศรอบเช้า · 8 พ.ย. 2026)

**commit ก่อนรัน · ห้ามแก้เกณฑ์หลังเห็นผล** · โค้ด: `experiments/48_e23_skip_fx.py` · เจ้าของโปรเจกต์สั่ง 8 พ.ย.

**รายงานเท่านั้น ไม่เปลี่ยนโมเดลหรือราคาที่ส่ง 9–13 พ.ย.** · เห็นผล E18, E18b, E21 และ E22 แล้ว จึงเป็นการทดลองหลังเห็นผลบนข้อมูลชุดเดิม

ข้อมูล: dataset `_wf` · แท่ง 60m · walk-forward ฝึกใหม่ทุก 20 วันทำการ ถึง 12 ต.ค. · ไม่ใช้ holdout ในการตัดสิน · เทียบบนแถวเดียวกับ E22 (เช้า 1,196 · บ่าย 992) · ทายราคาเท่านั้น ไม่ทายทิศทาง

## โมเดล

```
ราคาทาย = P(c) × exp(ส่วนที่ขยับ)
```

- **Skip:** P(c) ส่งตรงถึงคำตอบ โมเดลทายเฉพาะส่วนที่ขยับ · Linear สุดท้ายเริ่มที่ 0 จึงเริ่มฝึกจากการตอบ P(c)
- **เป้าหมาย:** ln(ราคาปลาย / P(c)) · หารด้วย SD ของข้อมูลฝึก · loss MSE · ไม่ปัดช่องราคา

| แบบ | รอบ | Input |
|---|---|---|
| `skip_tab` | เช้า, บ่าย | feature ตาราง + หุ้น |
| `skip_tab_fx` | เช้า | `skip_tab` + feature ต่างประเทศ |
| `skip_cnn` | เช้า, บ่าย | `skip_tab` + scalogram 56×56 |
| `skip_cnn_fx` | เช้า | `skip_cnn` + feature ต่างประเทศ |

- **feature ตาราง:** ชุดเดียวกับ E15 / E21
- **feature ต่างประเทศ:** `fx_spx`, `fx_thd_prem`, `fx_asia_gap`, `fx_usdthb` นิยามเดียวกับ E18b · ค่าว่างแทน 0 · ไม่ใช้รอบบ่าย
- **โครงข่าย:** CNN เหมือน `cnn2d_small` ของ E21 → Linear(8) → ReLU · ตาราง → Linear(8) → ReLU → Dropout 0.3 · ต่อกับตัวแปรหุ้น → Linear(1)
- **การฝึก:** Adam lr 1e-3 · weight decay 1e-2 · batch 64 · ≤ 30 epoch · patience 3 บน 20% วันท้ายของข้อมูลฝึก · เฉลี่ย 3 seed · normalize และ imputer fit บนข้อมูลฝึกเท่านั้น · ไม่จูน

## เกณฑ์ผ่าน

**ตัวแทนกำหนดล่วงหน้า:** เช้า `skip_cnn_fx` · บ่าย `skip_cnn` · เทียบ PR-A แยกแต่ละรอบ · ต้องครบทุกข้อ

1. ผลต่าง RMSE: ขอบบน CI 99.7% < 0
2. ผลต่าง RMSE รายหุ้น: ขอบล่าง CI 99.7% ≤ 0 ทุกหุ้น
3. ผลต่าง MAE: ขอบล่าง CI 99.7% ≤ 0

CI: block bootstrap รายวัน 2,000 ครั้ง · RMSE คำนวณใหม่ทุกรอบแบบจับคู่วันเดียวกัน

## รายงานเพิ่ม (ไม่ใช้ตัดสิน)

- ทุกแบบเทียบ PR-A และ P(c)
- CNN ช่วยไหม: `skip_cnn` − `skip_tab` · ต่างประเทศช่วยไหม: `skip_tab_fx` − `skip_tab` และ `skip_cnn_fx` − `skip_cnn`
