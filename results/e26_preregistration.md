# E26 — ลงทะเบียนเกณฑ์ล่วงหน้า (feature ใหม่ F1–F3 · 8 พ.ย. 2026)

**commit ก่อนรัน · ห้ามแก้เกณฑ์หลังเห็นผล** · โค้ด: `experiments/53_e26_features.py` · ที่มา: `feature_candidates.md` ที่เจ้าของโปรเจกต์ส่งให้ 8 พ.ย.

**รายงานเท่านั้น ไม่เปลี่ยนระบบส่งจริงกลางสัปดาห์ 9–13 พ.ย.** · ทดลองหลังเห็นผลก่อนหน้า บนข้อมูลชุดเดิม

ข้อมูล: dataset `_wf` · `as_of` 29 ต.ค. · walk-forward ถึง 12 ต.ค. · ไม่ใช้ holdout และข้อมูลใหม่ · feature ใช้เฉพาะข้อมูลก่อนจุดตัด

## กลุ่ม feature (เพิ่มครั้งละกลุ่ม)

| กลุ่ม | feature | ใช้กับ |
|---|---|---|
| F1 | `fm_set50_1d` = ln(SET50 C(d−1) / SET50 C(d−2)) | ทิศทาง, ราคา |
| F2 | `fo_on_1`, `fo_on_mean5`, `fo_on_mean20`, `fo_id_1`, `fo_id_mean5`, `fo_id_mean20` จาก Settrade 1d | ทิศทาง, ราคา |

**ไม่ได้ทำ:**
- `fm_set50_am`, `fm_set50_am_intra`, `fm_rel_am`: SET50 ระหว่างวันมีเฉพาะตั้งแต่ ส.ค. 2026 ไม่พอสำหรับ walk-forward
- **F4:** ไม่มีข้อมูลฟลอว์ต่างชาติและ NVDR ในเครื่อง

## แบบที่เทียบ

**ทิศทาง (F1, F2):** เช้า A-ud (`fd_lr`) + feature · บ่าย E15 MLP จูนด้วยวิธีเดิม + feature · เทียบแบบไม่มี feature และ E0-un · ตัวชี้วัด `acc_up_notup` และ log loss

**ราคา (F1, F2, F3):** ตัวแทน `PR-A+F` = `aprice_lr` และ `pprice_lr` + feature ด้วยกฎเดิม เทียบ PR-A และ P(c)

**รายงานเพิ่ม (ไม่ใช้ตัดสิน):**
- `S0-mean+F` = `adir_lr` และ `fd_lr` + feature ตามนิยามราคานิ่งเทียบราคาเปิด เทียบ `S0-mean`
- `S0-vol` (F3): (1 − P(นิ่ง)) × (2·P(ขึ้น|ไม่นิ่ง) − 1) × |r| ที่ทาย · |r| ทายด้วย Ridge α = 10 จาก `fv_*` แยกหุ้นและรอบ · ฝึกใหม่ทุก 5 วัน ฝึกขั้นต่ำ 120 วัน ก่อนนั้นใช้ค่าเฉลี่ย |r| ในอดีต

## เกณฑ์ผ่าน (CI 98.33% = Bonferroni 3 กลุ่มที่ทดสอบ · block bootstrap รายวัน 2,000 ครั้ง · แยกรอบ)

- **ทิศทาง:** ผลต่าง log loss ขอบบน < 0 และผลต่างความแม่นขอบบน ≥ 0 และทุกหุ้นผลต่าง log loss ขอบล่าง ≤ 0 · เทียบแบบไม่มี feature ของช่องนั้น
- **ราคา:** ผลต่าง RMSE ขอบบน < 0 และทุกหุ้นผลต่าง RMSE ขอบล่าง ≤ 0 และผลต่าง MAE ขอบล่าง ≤ 0 · เทียบ PR-A

Permutation importance: `fd_lr` + feature ฝึกจากวันก่อน 200 วันทดสอบท้าย วัดการเพิ่ม log loss บน 200 วันนั้น 5 รอบ

**ไม่ผ่าน:** รายงานผลต่างพร้อม CI ตามจริง · ไม่ผ่าน ≠ ไม่มีผล · ห้ามเปลี่ยนนิยามหลังเห็นผล · ไฟล์ใน `results/e26/` ไม่มีราคาดิบ
