## 1. ข้อมูลฝึกเทียบทดสอบ

Gain = log loss ของ E0 − log loss ของโมเดล บนแถวเดียวกัน (บวก = ดีกว่าสถิติพื้นฐาน) · E0 = สัดส่วนในข้อมูลฝึก แยกหุ้นและรอบ

- **train gain:** fit ใหม่ ณ จุดเริ่มแต่ละช่วงจูนของ E15 แล้ววัดบนข้อมูลฝึกนั้น เฉลี่ยทุกช่วง
- **inner gain:** จาก inner CV ที่บันทึกไว้ (E15, E17b)
- **test gain:** จาก walk-forward ที่บันทึกไว้ พร้อม CI 95% จาก block bootstrap รายวัน

แบบที่ตรวจ: A-ud, A-un, A-price, p_price, 7 โมเดลของ E15 และ 7 โมเดลของ E17b ทั้งสองเป้าหมาย

| ระดับ | เงื่อนไข |
|---|---|
| **overfit ชัด** | train gain ≥ 0.010 และ test gain ≤ 0 |
| **มีช่องว่าง** | train gain − test gain ≥ 0.005 แต่ไม่เข้าระดับบน |
| **ไม่พบช่องว่างมาก** | train gain − test gain < 0.005 |

## 2. PBO จากการเลือกแบบ

CSCV แบบเดียวกับ E15 (S = 10) บน −log loss รายวัน แยกรอบ ใช้เฉพาะวันที่ทุกแบบมีผล · แต่ละกลุ่มต้องมีอย่างน้อย 3 แบบ

กลุ่ม: E9, E12, E10, EZOO, รอบ 1–3 รวมกัน, E15, E14–E16 + E18 ทิศทางรอบ 7 รวมกัน, E17b, ราคารอบ 7 รวมกัน, E19 (S = 6)

**> 0.5 = เสี่ยงจากการเลือกแบบ** · รายงานผลต่างระหว่างแบบดีสุดกับแย่สุดคู่กัน เพราะถ้าทุกแบบเกือบเท่ากัน PBO ใกล้ 0.5 ได้แม้ไม่มีแบบใดมีฝีมือ · E19 มี 6 วัน จึงรายงานว่าใช้สรุปไม่ได้

## 3. Learning curve ของ CNN

ทุกไฟล์ `*_curves.csv` · ต่อ fold และ seed หา epoch ที่ val loss ต่ำสุด · **overfit เร็ว** = ค่ามัธยฐาน epoch ที่ดีที่สุด ≤ 3 และ train loss ยังลดต่อหลังจากนั้น

## 4. ความนิ่งตามเวลา

แบ่งช่วงทดสอบเป็น 3 ส่วนเท่ากันตามวัน รายงาน test gain และ CI 95% ของ A-ud เช้า/บ่าย, A-un และ E15 MLP บ่าย · ถ้าส่วนหลังแย่ลงต่อเนื่อง จะรายงานว่าอาจเสื่อม

## 5. Holdout

เทียบ gain บน walk-forward กับ holdout 14–29 ต.ค. (เปิดดูไปแล้ว ใช้รายงานเท่านั้น รอบละ 20 แถว จึงสรุปไม่ได้)
