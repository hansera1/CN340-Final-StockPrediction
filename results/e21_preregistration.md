# E21 — ลงทะเบียนเกณฑ์ล่วงหน้า (ablation: baseline → ตาราง → 1D-CNN → scalogram → fusion · 7 พ.ย. 2026)

**commit ก่อนรัน · ห้ามแก้ส่วนบนหลังเห็นผล** · โค้ด: `experiments/44_e21_ablation.py` · ที่มา: ข้อเสนอแนะที่เจ้าของโปรเจกต์ส่งให้ 7 พ.ย.

**รายงานเท่านั้น ไม่เข้าการตัดสิน 4 ช่อง และไม่เปลี่ยนโมเดลที่ส่ง 9–13 พ.ย.** · เป็นการทดลองหลังเห็นผลบนข้อมูลชุดเดิม โอกาสบังเอิญจึงสูง

ข้อมูล: dataset `_wf` (ATC + 12:35) · แท่ง 60m · `as_of` ถึง 12 ต.ค. · **ไม่ใช้ holdout** · เป้าหมาย up_notup · pooled สองหุ้น แยกรอบ · walk-forward ฝึกใหม่ทุก 20 วันทำการ (วันทดสอบชุดเดียวกับ E10) · ไม่จูน

## คำถาม

CNN ชนะแบบง่ายกว่าหรือไม่ เมื่อเทียบบนแถวเดียวกัน ถ้าไม่ชนะพร้อม CI ให้สรุปว่าไม่ชนะ โดยไม่จูนสถาปัตยกรรมต่อ

## ขั้นบันได

| ลำดับ | แบบ | Input | สเปกตายตัว |
|---|---|---|---|
| 0 | `e0` | สัดส่วนในอดีตแยกหุ้น | E0-un ชุดเดียวกับรายงานก่อนหน้า |
| 1 | `return_lr` | ผลตอบแทน 1, 6, 28 แท่งล่าสุด + หุ้น | LR C = 0.001 |
| 2 | `tab_lr` | feature ชุด E15 | LR C = 0.001 |
| 3 | `cnn1d_3` | 56 แท่ง 3 ช่อง: r, \|r\|, log volume + หุ้น | small 1D-CNN |
| 4 | `cnn1d_ext` | 8 ช่อง: 3 ช่องแรก + open–close return, high–low range, realized vol 6 แท่ง, volume surprise เทียบเวลาเดียวกัน 20 วันก่อน, เวลาถึงปิดตลาดของแท่ง + หุ้น | small 1D-CNN |
| 5 | `cnn2d_small` | scalogram 3 ช่องเดิม ย่อเหลือ 56×56 + หุ้น | small 2D-CNN ไม่ใช้ pretrained |
| 6 | `resnet18_s2` | scalogram 3 ช่องเดิม | ใช้ผลเดิม `cnnb_resnet18_s2` ไม่ฝึกใหม่ · ไม่มีตัวแปรหุ้น |
| 7 | `fusion` | ช่องของ `cnn1d_ext` + feature ของ `tab_lr` + หุ้น | small 1D-CNN + หัวตาราง |

**โครงข่าย:** 1D: Conv(16, k=5) → ReLU → Dropout 0.3 → Conv(16, k=5) → ReLU → GAP · 2D: Conv(8) → Pool → Conv(16) → Pool → Conv(16) → GAP · fusion: feature ตาราง → Linear(8) → ReLU → Dropout 0.3 · ต่อด้วย Linear(1)

**การฝึก:** Adam lr 1e-3 · weight decay 1e-2 · batch 64 · ≤ 30 epoch · patience 3 บน 20% วันท้ายของข้อมูลฝึก · เฉลี่ย 3 seed · ไม่มี flip หรือ rotate · ค่า normalize และ imputer fit บนข้อมูลฝึกเท่านั้น

## สิ่งที่ไม่ทำ และเหตุผล

- **Multi-resolution 1m + 5m/15m:** ข้อมูล 1m มีประมาณ 14 วัน และ 5m ประมาณ 60 วัน จึงทดสอบบนวันชุดเดียวกันไม่ได้
- **`time_to_session_close` ระดับแถว:** แต่ละรอบมีจุดตัดเดียว ค่าจึงคงที่ภายในรอบ · ใช้เวลาระดับแท่งแทนใน `cnn1d_ext`
- **TCN และสถาปัตยกรรมอื่น:** ไม่เพิ่ม เพื่อไม่เพิ่มจำนวนการเทียบ

## การเทียบ และเกณฑ์ "ชนะ"

| คำถาม | a เทียบ b |
|---|---|
| ราคาอย่างเดียวดีกว่าสถิติไหม | `return_lr` − `e0` |
| feature ตารางช่วยไหม | `tab_lr` − `return_lr` |
| ลำดับดีกว่าตารางไหม | `cnn1d_3` − `tab_lr` |
| ช่องตลาดเพิ่มช่วยไหม | `cnn1d_ext` − `cnn1d_3` |
| scalogram ดีกว่าลำดับไหม | `cnn2d_small` − `cnn1d_ext` |
| pretrained ช่วยไหม | `resnet18_s2` − `cnn2d_small` |
| fusion ดีกว่าตารางไหม | `fusion` − `tab_lr` |
| fusion ดีกว่าลำดับไหม | `fusion` − `cnn1d_ext` |

แยกเช้าและบ่าย · CI bootstrap รายวัน 99.7% (รายงาน 95% ด้วย)

**ชนะ:** ผลต่าง log loss ขอบบน CI 99.7% < 0 **และ** ผลต่างความแม่นขอบบน ≥ 0 **และ** log loss ไม่แย่กว่าอย่างมีนัยสำคัญในหุ้นใดหุ้นหนึ่ง · นอกเหนือจากนี้รายงานว่า "ไม่พบว่าชนะ"

รายงานเพิ่ม: test gain เทียบ E0, สัดส่วนที่ทาย "ขึ้น", epoch ดีสุด (overfit เร็ว) และ PBO ของกลุ่ม
