## ขั้น A: ทาย gap (ĝ)

- เป้าหมาย gap = ln(`p_start` / `p_ref`) ของแถวรอบเช้า
- feature: `fx_spx`, `fx_thd_prem`, `fx_usdthb` นิยามเดิม และ `fx_asia_gap` = ค่าเฉลี่ยของ `fx_n225_gap` กับ `fx_kospi_gap` ที่มีค่า · ไม่มีทั้งคู่ = 0 · ค่าว่างอื่น = 0 และรายงานจำนวน
- `Ridge` แยกหุ้น · StandardScaler fit บนข้อมูลฝึก · α ∈ {0.1, 1, 10, 100} เลือกด้วย MSE จาก time-series CV 3 fold ในข้อมูลฝึก (`inner_folds`) · intercept ปกติ
- ĝ ของวัน t มาจากโมเดลที่ฝึกด้วยวัน < t เท่านั้น · ฝึกใหม่ทุก 5 วันทำการ แบบ expanding · ฝึกขั้นต่ำ 120 วัน · ก่อนนั้น ĝ = 0
- ĝ ชุดเดียวใช้ทั้งแถวฝึกและแถวทดสอบของขั้น B · assert `gap_model_train_end < date` ทุกแถว

**จุดหยุด:** ถ้า correlation นอกตัวอย่างของหุ้นใดต่ำกว่าขอบล่าง CI ของ H1 เดิม (ADVANC 0.252, KBANK 0.182) ให้หยุดหาบั๊กก่อนไปขั้น B

## ขั้น B: 3 แบบ (Bonferroni CI 98.33%)

P(c)′ = ปัดช่องราคา( P(c) × exp(ĝ) ) โดยช่องราคาคิดจากระดับของ P(c)′

| แบบ | ราคาจุด | ฝึกโมเดลราคาใหม่ |
|---|---|---|
| H2b-0 | P(c)′ | ไม่ |
| H2b-rule | `price_rule` รอบ P(c)′ | A-price′ และ p_price′ |
| H2b-mean | P(c)′·exp(P(สูงกว่า)·E[z′\|สูงกว่า] + P(ต่ำกว่า)·E[z′\|ต่ำกว่า]) ไม่ปัด | ชุดเดียวกับ H2b-rule |

ตัวเทียบ (ไม่นับใน Bonferroni): PR-A (ผล C1235 เดิม) และ P(c)

- แทน `p_ref` เฉพาะแถวเช้าเพื่อสร้างป้าย · คอลัมน์ feature ใช้ค่าเดิม ไม่คำนวณจาก P(c)′ · z′ = ln(P(12:30) / P(c)′)
- feature: ชุดเดิมของ `E9FLAT/aprice_lr` และ `E9FLAT/pprice_lr` + ĝ และ |ĝ| · สเปกโมเดล, walk-forward และ C เดิมผ่าน `run_variant`
- **`aprice_lr` เดิมฝึกรวมสองรอบ จึงคงไว้ · แถวบ่ายใช้ ĝ = 0 และ p_ref เดิม** เพราะไม่ได้เลื่อน · รายงานเฉพาะแถวเช้า
- E[z′|สูงกว่า], E[z′|ต่ำกว่า]: ค่าเฉลี่ยแบบ expanding ของวันก่อนวันทาย แยกหุ้น รอบเช้า
- ช่วงราคา: quantile ของ z′ จากวันก่อนบล็อกทดสอบ แยกหุ้น หักค่ามัธยฐาน แล้วคูณรอบราคาจุด · H2b-0 และ H2b-rule ปัดช่องราคา · H2b-mean ปัด 2 ตำแหน่งตามระบบราคาทศนิยม · PR-A ใช้ `E9_baseline_ud` ของ C1235

## เกณฑ์ผ่าน (เทียบ PR-A · รอบเช้า walk-forward ทั้งช่วง · ต้องครบทุกข้อ)

1. ผลต่าง RMSE รวมรอบเช้า: ขอบบน CI 98.33% < 0
2. ผลต่าง RMSE รายหุ้น: ขอบล่าง CI 98.33% ≤ 0 ทุกหุ้น
3. ผลต่าง MAE รวมรอบเช้า: ขอบล่าง CI 98.33% ≤ 0
4. coverage ช่วง 50% และ 80% รวมรอบเช้า: |coverage − เป้า| ≤ ค่าเดียวกันของ PR-A ทั้งสองระดับ

CI: block bootstrap รายวัน 2,000 ครั้ง · RMSE คำนวณใหม่ทุกรอบแบบจับคู่วันเดียวกัน

**ผ่านมากกว่าหนึ่งแบบ:** เลือก RMSE เฉลี่ยต่ำสุดใน inner CV = 3 บล็อกท้าย (`inner_folds`) ของข้อมูลฝึกครั้งสุดท้าย ไม่ใช้ผลชุดทดสอบ

**ไม่ผ่าน:** รายงานผลต่างพร้อม CI ตามจริง · ไม่ผ่าน ≠ ไม่มีผล · ห้ามเปลี่ยน α, รวม feature ใหม่ หรือแก้นิยามหลังเห็นผล
